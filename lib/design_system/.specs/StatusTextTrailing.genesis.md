# StatusTextTrailing Genesis

## Inspiration

Backfilled from `lib/design_system/src/status_text_trailing.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Standardizes trailing status text for list rows and compact summaries.
- Keeps it as a slot primitive rather than a custom list container.
- Uses semantic color and text-theme styles to align with DS status treatment.
