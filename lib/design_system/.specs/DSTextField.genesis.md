# DSTextField Genesis

## Inspiration

Backfilled from `lib/design_system/src/text_field.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Wraps text input styling as the design-system text field abstraction.
- Keeps validation, controllers, and data ownership with callers.
- Uses M3 text field behavior with DS token alignment for spacing and shape.
