# ListSectionHeader Genesis

## Inspiration

Backfilled from `lib/design_system/src/list_section_header.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Standardizes section labels above grouped list content.
- Avoids custom list container behavior; it is a header slot used with M3 list surfaces.
- Uses tokenized spacing and typography to preserve list scanning rhythm.
