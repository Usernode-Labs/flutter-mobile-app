# InfoRow Genesis

## Inspiration

Backfilled from `lib/design_system/src/info_row.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Provides a small label/value row primitive for settings, diagnostics, and detail views.
- Keeps formatting decisions with the caller while standardizing layout and emphasis.
- Uses text-theme styles and token spacing instead of hardcoded row dimensions.
