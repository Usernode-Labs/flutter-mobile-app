# StatusBadge Genesis

## Inspiration

Backfilled from `lib/design_system/src/status_badge.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Provides a compact semantic status slot for cards, rows, and lists.
- Uses `AppSemanticColors` for chromatic meaning instead of M3 structural roles.
- Keeps labels and status selection caller-owned.
