# ResultPage Genesis

## Inspiration

Backfilled from `lib/design_system/src/result_page.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Provides a reusable success/error/result surface for bounded flows.
- Keeps result content, actions, and callbacks caller-owned.
- Uses semantic color and tokenized vertical rhythm to support high-trust flow completion.
