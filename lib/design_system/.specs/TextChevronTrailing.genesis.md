# TextChevronTrailing Genesis

## Inspiration

Backfilled from `lib/design_system/src/text_chevron_trailing.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Provides a reusable trailing text plus chevron affordance for navigable rows.
- Stays a slot widget so M3 `ListTile` remains the row container.
- Uses tokenized icon sizing and typography for consistent row rhythm.
