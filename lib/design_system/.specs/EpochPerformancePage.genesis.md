# EpochPerformancePage Genesis

## Inspiration

Backfilled from `lib/design_system/src/epoch_performance_page.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Captures epoch performance as a DS page surface with plain data inputs.
- Keeps blockchain/provider state outside the DS layer.
- Uses DS cards, rows, and tokenized hierarchy to make performance metrics scannable.
