# DappAvatar Genesis

## Inspiration

Backfilled from `lib/design_system/src/dapp_avatar.dart`, tests, and Widgetbook coverage during DS harness standardization.

## Design Decisions

- Provides a compact visual identity slot for decentralized app rows and cards.
- Keeps image/fallback handling presentation-only and caller-controlled.
- Uses tokenized sizing so avatars align with list and card keylines.
